# Smart Mood & Productivity Analyzer

A Python-based wellness and productivity analyzer that tracks daily habits, analyzes mood, calculates a wellness score, and generates visual insights using Matplotlib.

## 🚀 Features

- 🧠 Mood analysis
- 📊 Productivity analysis
- 💯 Wellness score out of 100
- ⏱️ Sleep, study, and screen-time analysis
- 💧 Water and exercise tracking
- 💡 Personalized daily recommendations
- 💾 Daily data storage using file handling
- 📈 Data visualization with Matplotlib

## 🛠️ Technologies Used

- Python
- Matplotlib
- File Handling
- VS Code

## ⚙️ How It Works

The program asks the user for daily information such as:

- Sleep hours
- Study hours
- Screen time
- Water intake
- Exercise duration
- Mood

It then analyzes the information and generates a productivity level, wellness score, personalized feedback, and visual charts.

## 📈 Visualizations

The project generates three visualizations:

1. My Wellness Score
2. Daily Time Analysis
3. Daily Water & Exercise

This project was created to practice Python programming concepts and apply them in a practical data-analysis project.
